Data

All the data behind the drug test

Structures, optimizer logs, the AI agent's decisions, the forces behind the Hessian, the frequencies and the infrared tables. File sizes and SHA-256 checksums are in the manifest.

Structures

XYZ files in Å. The starting structure, the first stored geometry and the final structure of each run, and the Module 2 structures.

Runs and decisions

Per-step energies and forces, run settings, the event log, and every prompt and answer of the AI agent.

Vibrations and infrared

73 saved force-and-dipole files, the 30 frequencies with intensities, thermochemistry, and the 25-band comparison table.

Units. Energies in eV unless a field says Eh (hartree). Module 2 forces are in true eV/Å. Module 1 force values (fmax) are in the Module 1 code's own units, about 1.89 times smaller than true eV/Å; run_meta.json records this.

Starting structures. The deformed starting structures of Runs 2 and 3 are not stored as separate files. first_stored_geometry.xyz holds the first geometry the run saved.
