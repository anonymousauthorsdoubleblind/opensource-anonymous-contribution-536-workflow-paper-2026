Run log · Module 1

Three starts, one structure: the run log

The log of the three Module 1 optimization runs (Skala-1.1 / def2-SVP). Turn the molecules, compare the starts, and see what each run released and where it ended.

Three optimization runs of the same molecule, 5-fluorouracil (T1, the diketo form). Run 1 starts from a normal structure. Run 2 starts from a structure bent on purpose, about 2.5 eV above the minimum by the xTB check and 3.11 eV above the final energy by Skala. Run 3 is bent much harder, about 6 eV by xTB and 6.38 eV by Skala, close to the most strain at which the molecule still keeps all its bonds. A 50 eV structure cannot be built with the bonds intact. Run 1

Notebook M1_5FU_agentic_geometry_L4. Start: a force-field (MMFF) structure nudged by 0.01 Å. The agent run begins at a step size of 0.005 Å.

    Run 2

    Notebook M1B_5FU_deformed_start_L4. Same optimizer, same agent, same stop rule, same basis.

      Run 3

      Notebook M1C_5FU_very_deformed_start_L4, gradient budget 400. A stress test of the same-structure rule. Geometry only: no vibrations or infrared were computed from this start.

        How to read this log. Module 1 is geometry only. The vibrations and the infrared were computed once, from the Run 2 (3.1 eV) result, at a larger basis set (Findings). Nothing was computed from the Run 3 start except its geometry. "Same shape" means the rule fixed before the runs: under 0.02 Å and under 10 meV. The xTB energies only designed the starts; the Skala energies above the final structure are 3.11 eV (Run 2) and 6.38 eV (Run 3). The AI agent that supervised each run is described on The agent.
