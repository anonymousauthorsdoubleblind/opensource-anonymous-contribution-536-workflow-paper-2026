How it ran

The workflow, run unchanged on the drug

The open-source workflow has four modules. The drug test used the first two. The other two (NMR and molecular properties) were used for the annulenes and are described on the main site.

Module 1 · used

Agentic optimizer

Rolls a rough shape down to the bottom of its energy valley. L-BFGS on Skala-1.1 forces, supervised by an AI agent behind a guard.

Skala-1.1 / def2-SVP · three starts

Module 2 · used

Hessian and infrared

Re-optimizes in a larger basis, then shakes every atom to get all vibrations, their infrared strengths and the thermochemistry.

Skala-1.1 / def2-TZVP · Run 2 shape

Module 3 · not used here

NMR workflow

Predicts NMR signals for comparison with measured spectra. Used for the annulenes only.

Module 4 · not used here

Molecular properties

Orbitals and charge maps on a relaxed structure. Used for the annulenes only.

Module 1 · three starts, one structure

Each run used Skala-1.1 with the def2-SVP basis set (141 basis functions) on one cloud GPU (NVIDIA L4). The optimizer stops when the largest force on any atom falls below its target. A "gradient evaluation" is one full force calculation, the expensive unit of work.

The AI agent's decisions

The agent is a large language model (Gemini models gemini-4-argon and gemini-3.8-flash) called at fixed moments: before the run, at the start of each pass, when code-measured triggers fire, and at the end. It answers by choosing one action from a fixed menu. It never writes coordinates. Every answer goes through a guard that bounds the change and a probation period that can roll it back.

All calls in the three drug runs ended in "continue" except these setting changes. Each one raised the largest allowed step (maxstep, in Å) because steps were pinned at the limit while the energy kept falling. The agent page follows each run step by step.

Module 2 · vibrations and infrared

  1. Take the relaxed Run 2 structure. Module 2 starts from the structure that Module 1 relaxed from the 3.1 eV start. This is why we say "the workflow started 3.1 eV bent".
  2. Re-optimize in a larger basis. Skala-1.1 / def2-TZVP (297 basis functions) until the largest force is below 0.01 eV/Å. Reached 0.0099 eV/Å in three passes and 19 gradient evaluations.
  3. Shake every atom. Each of the 12 atoms is moved by ±0.01 Å along x, y and z: 72 displaced structures plus the centre, 73 force calculations. The forces and the dipole moment are saved at each one (data/module2_T1/ir_cache/).
  4. Build the Hessian. From the force changes (central differences) the code builds the 36 × 36 matrix of spring constants, the Hessian.
  5. Read off vibrations and infrared strengths. The Hessian gives 30 vibrations; the dipole changes give each one's infrared intensity (km/mol). Thermochemistry (zero-point energy, enthalpy, free energy at 298 K) uses the harmonic, ideal-gas, rigid-rotor model.
  6. Compare with the lab. 25 bands between 1800 and 300 cm⁻¹ are paired with the argon-matrix bands of Ivanov et al. (2017), by frequency order, with the character of key bands checked.

Software for Module 2: skala 2026.9, GPU4PySCF 1.8.1, PySCF 2.14.0, ASE 3.29.0, Python 3.13 (data/module2_T1/environment.json).
