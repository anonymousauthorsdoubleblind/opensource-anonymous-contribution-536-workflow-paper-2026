Reproduce

Three ways to check the result

Start with the quick check. It needs no GPU, no account and no API key.

Steps

2 minutes · any computer

A · Recompute the numbers

Needs Python 3 only.

python code/analysis/ir_compare.py

Prints 25 bands, scale factor 0.9736, 11.0 cm⁻¹ after scaling, largest error 29.2 cm⁻¹, rank correlation 0.86.

10 minutes · any computer

B · Redraw the supplement figures

Rebuilds the Hessian from the 73 saved force files.

pip install numpy matplotlib ase pillow
FIG_OUT=out python code/figure_scripts/make_hess.py
FIG_OUT=out python code/figure_scripts/make_viz.py
FIG_OUT=out python code/figure_scripts/make_table.py
about 2 to 3 hours · Colab GPU

C · Rerun the calculations

Runs Modules 1 and 2 with Skala-1.1. Needs a Google account, Colab GPU time and your own Gemini API key for the agent.

Full rerun, in order

  1. Module 1, standard start. Open M1_5FU_agentic_geometry_L4.ipynb in Colab on an L4 GPU. Keep SHAPE = "T1". Add Colab secrets GEMINI_API_KEY (and optionally GEMINI_API_KEY_2). Run all. About 20 to 40 minutes.
  2. Module 1, deformed start (Run 2). Run M1B_5FU_deformed_start_L4.ipynb the same way. Its same-structure check must pass before Module 2 will use the result.
  3. Optional: very deformed start (Run 3). M1C_5FU_very_deformed_start_L4.ipynb. Geometry only in the paper.
  4. Module 2. Run M2_5FU_hessian_thermo_IR_A100.ipynb on an A100 with INPUT_SOURCE = "deformed" and SHAPES = ["T1"]. It writes freq_ir.csv, thermo.json and the ir_cache folder to Google Drive. About 35 to 50 minutes.
  5. Compare. Pair the new freq_ir.csv with data/ir_reference/5fu_T1_Ar_matrix_bands.csv and run step A on the new table.

What will differ. The AI agent is a language model, so its wording and possibly its choices can differ between runs. GPU arithmetic is not bit-for-bit repeatable. Expect the same structure and frequencies within small tolerances, not identical log files.
