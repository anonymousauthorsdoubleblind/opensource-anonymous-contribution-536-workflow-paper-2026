Code

The code, and what each piece does

Four notebooks ran the calculations on Google Colab GPUs. Four small scripts redraw figures and recompute the infrared numbers from the released data. Everything is under the MIT licence.

Map of the code

FileModuleWhat it doesRuns on
code/notebooks/M1_5FU_agentic_geometry_L4.ipynb1Agentic geometry optimization from the standard start (Run 1). Smoke test first, then one supervised run, def2-SVP. Writes the hand-off structure for Module 2.Colab, NVIDIA L4
code/notebooks/M1B_5FU_deformed_start_L4.ipynb1Same, from a deliberately deformed start (Run 2). Checks that it ends at the Run 1 structure before Module 2 may use it.Colab, NVIDIA L4

Inside Module 1

  • Optimizer: L-BFGS (ASE) on Skala-1.1 forces from GPU4PySCF, run in passes with a gradient budget.
  • Monitor: code measures each step (step size against the cap, energy trend, curvature) and fires triggers.
  • Agent: a language model chooses one action from a fixed menu (continue, change settings, reset memory, and a few more). Free helper functions give it evidence; it must cite that evidence.
  • Guard and probation: every change is bounded, logged and can be rolled back. A same-structure check guards the hand-off to Module 2.

Not included here. The main paper's other figures (Figures 1 and 2 of the drug test and the appendix figures) were drawn with separate plotting scripts that are not in this package yet. Their underlying numbers are all in the data folder. Notebooks for the annulenes and for Modules 3 and 4 are on the main site.
